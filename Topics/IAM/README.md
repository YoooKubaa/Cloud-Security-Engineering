# 🔑 AWS Identity and Access Management (IAM) Security

Welcome to the **IAM Security** module. In cloud environments, identity is the primary security perimeter. This section explores how identities are structured, abused, federated, and defended.

## 📂 Sub-modules Architecture

1. **[Users vs Roles vs Policies](./Users_vs_Roles_vs_Policies/README.md)** - Core IAM primitives, trust policies, and permission models.
2. **[Abuse Patterns](./Abuse_Patterns/README.md)** - Common privilege escalation vectors and credential misuse patterns.
3. **[Permission Boundaries](./Permission_Boundaries/README.md)** - Delegating administration safely using boundaries.
4. **[Machine Identity](./Machine_Identity/README.md)** - Securing non-human workloads, EC2 instance profiles, and IAM roles for tasks.
5. **[Service Accounts](./Service_Accounts/README.md)** - Managing service-to-service access and reducing blast radius.
6. **[Federation](./Federation/README.md)** - External identity providers, SAML, OIDC, andassume-role workflows.
7. **[SSO](./SSO/README.md)** - AWS IAM Identity Center and centralized multi-account access management.
8. **[AWS Config and SCPs](./AWS_Config_and_SCPs/README.md)** - Preventive and detective guardrails across AWS organizations.
